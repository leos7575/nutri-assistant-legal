Reglas y alcance de uso de Nutri Assistant

Estas Condiciones regulan el uso de Nutri Assistant, un sistema de asistencia y apoyo para atención nutricional mediante WhatsApp y herramientas digitales asociadas.

1. Uso del servicio

El usuario podrá utilizar el servicio para realizar consultas relacionadas con su seguimiento nutricional, revisar información previamente registrada, consultar citas y comunicarse con el nutriólogo cuando sea necesario.

2. Alcance del asistente

El asistente automatizado puede responder utilizando información registrada en el sistema y herramientas autorizadas. Las respuestas automáticas son de apoyo y no sustituyen el criterio profesional del nutriólogo.

3. Información de salud

El usuario es responsable de proporcionar información veraz y suficiente cuando solicite orientación. Cualquier síntoma, condición médica, medicamento, alergia o situación relevante debe ser informado directamente al profesional responsable.

4. No es un servicio de emergencias

Nutri Assistant no es un servicio de urgencias. Ante síntomas graves, pérdida del conocimiento, dificultad para respirar, dolor intenso, reacción alérgica severa u otra emergencia, el usuario debe acudir inmediatamente a los servicios médicos o de emergencia correspondientes.

5. Intervención humana

El sistema puede detectar que una consulta requiere atención del nutriólogo y cambiar la conversación a modo de atención humana. El tiempo de respuesta puede variar según disponibilidad y prioridad.

6. WhatsApp y proveedores externos

El servicio utiliza WhatsApp Business Platform y puede depender de servicios de terceros. La disponibilidad puede verse afectada por interrupciones, mantenimiento, cambios de API o fallas ajenas a Nutri Assistant.

7. Uso adecuado

No está permitido utilizar el servicio para enviar contenido ilegal, abusivo, fraudulento, automatizaciones maliciosas o para intentar obtener acceso no autorizado a sistemas o información de otras personas.

8. Disponibilidad y cambios

Las funciones pueden modificarse, suspenderse o actualizarse para mejorar el servicio, corregir errores, reforzar seguridad o adaptarse a cambios de los proveedores tecnológicos.

9. Privacidad

El tratamiento de datos se describe en la Política de Privacidad.
