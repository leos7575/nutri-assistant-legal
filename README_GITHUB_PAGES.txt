SUBIR A GITHUB PAGES
--------------------
1. Crea un repositorio nuevo, por ejemplo:
   nutri-assistant-legal

2. Sube estos 5 archivos a la raíz del repositorio.

3. En GitHub:
   Settings > Pages

4. En "Build and deployment":
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)

5. Guarda.

GitHub mostrará una URL parecida a:
https://TU_USUARIO.github.io/nutri-assistant-legal/
